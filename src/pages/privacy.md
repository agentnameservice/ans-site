## Page view counting

This site uses [GoatCounter](https://www.goatcounter.com/) to count page views.
For each view, GoatCounter records the page path, the referring site, the
browser and operating system family, the screen width, the language, and an
approximate location derived from the IP address. It does not store IP
addresses, full browser identifiers, or any tracker ID, and it does not set
cookies or store anything in the browser. Repeat visits are grouped for up to
eight hours in memory only, without a persistent identifier. When JavaScript is
disabled, a one-pixel image request reports the page path only.

GoatCounter is open source and operated by Martin Tournoij in Ireland, with
servers hosted by Hetzner Online GmbH in Finland and Germany. The statistics stay
in the project's GoatCounter account and are not shared with third parties. See the
[GoatCounter privacy policy](https://www.goatcounter.com/help/privacy) for
details.

## Hosting and external links

The hosting provider may process standard request information, such as an IP
address, to serve pages and operate its infrastructure. For GitHub Pages hosting,
see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

Links to GitHub, news publishers, and other sites take you to services with their
own privacy policies. This site does not embed those services or load third-party
fonts.
